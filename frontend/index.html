How to add to Gmail

  1. Click Copy Signature above
  2. Click Open Gmail Settings below — it opens in a new tab
  3. Scroll down to Signature and click Create new or select an existing one
  4. Click inside the signature editor and paste (Ctrl+V / ⌘+V)
  5. Scroll to the bottom of the page and click Save Changes
